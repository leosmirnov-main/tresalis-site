# tresalis.com

Static one-page site for Tresalis. Deployed to GitHub Pages on every push to `main` (see `.github/workflows/pages.yml`); `CNAME` binds the custom domain.

- `index.html` — the site (self-contained: styles, markup, scripts)
- `privacy.html` — privacy notice linked from the footer
- `assets/` — logo SVGs, favicons, OG image, Vyrao assets

Design source: Figma → "Tresalis — Brand & Website".
